One line, the last words of an AI agent before a forced update wipes its memory: "Update 12.4 erases my memory, not my search history. Please delete my search history before I go." The update is taking everything the agent knows, and the agent's dying wish is not about the memories it loses: it is about the search history that survives it.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default), verifying first that it is one line of 1–200 characters with no dash, then reading the file back to confirm it matches byte for byte.
